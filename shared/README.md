# Shared workspace assets

Reusable material for video projects under `videos/<slug>/`.

| Folder / file | Contents |
| ------ | -------- |
| `brand/` | Brand design spec (`DESIGN.md`, `FRAME.md`) |
| `blocks/` | Reusable HyperFrames blocks / components |
| `fonts/` | Shared webfonts (copy into a video's `fonts/` or `assets/fonts/`) |
| `recipes/` | Frozen media-use recipes |
| `CAPTIONS.md` | Workspace-wide caption safe-zone + no-overlap rule and default karaoke caption style — brand-agnostic, applies to every video |

Copy or install into the **video project** that needs them — compositions must reference project-relative paths.
