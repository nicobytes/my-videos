# Workspace

Este documento quedó reemplazado por [SETUP.md](SETUP.md) (instalación y flujo de trabajo) y [CLAUDE.md](CLAUDE.md) (reglas para agentes).

Resumen:

- Un video = un proyecto HyperFrames en `videos/<slug>/`.
- Crear un video: `pnpm new-video <slug>`.
- Trabajar en un video: `cd videos/<slug>`, luego `pnpm run check`, `npx hyperframes preview --background` y `pnpm run render`.
